# aws-resilient-platform

## The problem
A mid-sized online retailer loses revenue every time its web app goes down
or slows under peak traffic. Deployments are manual, environments drift,
and nobody can rebuild production quickly after a failure.

## What success looks like
- The app stays available if a single server or availability zone fails
- Any environment can be rebuilt from code in under 30 minutes
- Costs are visible and stay within a defined budget
