# 1. Record architecture decisions

Date: 2026-09-19

## Status
Accepted

## Context
We need a lightweight way to capture why significant technical choices
were made, so future contributors (and reviewers) understand the trade-offs.

## Decision
We will keep Architecture Decision Records in docs/decisions, numbered
sequentially, using the Nygard format: Title, Status, Context, Decision,
Consequences.

## Consequences
Every significant choice gets a short markdown file. Superseded decisions
are kept and marked "Superseded by ADR-000X" rather than deleted.
